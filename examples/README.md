# Examples

- `input.json` — a combined discovery + URL run with prices and reviews.
- `hotels.sample.json` — one hotel row (default dataset).
- `reviews.sample.json` — a text review and a rating-only review.

Run it: paste `input.json` into the [actor's input](https://apify.com/factden/booking-com-scraper?fpr=factden), or POST it to the Apify API (see the repo README).
